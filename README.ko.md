# 동그란 순간 · AI 티코스터 공방

## 작은 시작 파일로 설치

웹앱의 **작은 시작 파일 받기 · 4KB**로 압축을 내려받아 풀고 **START-LITE.cmd**를 실행하세요. 처음 한 번 필요한 프로그램을 받습니다. 호환 Codex가 있으면 약 82MB, 없으면 전체 묶음 약 240MB가 필요합니다. 재실행 때는 설치된 파일을 사용합니다. 사진·결과는 시작 폴더의 `app/data`에 저장합니다. 기존 전체 묶음의 자료는 자동 이관하지 않습니다.

## 전체 묶음으로 다른 Windows 노트북에서 시작

1. `AI-Coaster-Studio-Windows-x64.zip` 전체를 압축 해제하세요. ZIP 안에서 실행하지 마세요.
2. 폴더 안의 **START.vbs**를 더블클릭하세요. 이 PC 연결 화면이 열립니다. **이 PC를 웹 운영자 화면에 연결**을 누르면 GitHub 웹앱으로 이동합니다. 브라우저의 이 기기 앱·로컬 네트워크 접근을 허용하세요. 실행이 어려우면 **START.cmd**를 실행해 오류를 확인하세요.
3. 첫 화면에서 현재 운영자 PC 이름과 Codex 연결 상태를 확인하세요. 최초 사용 시 **Codex로 로그인하기** → **공식 로그인 페이지 열기**를 눌러 표시된 기기 코드를 입력하세요. 연결 확인 후 **공방 시작하기**를 누르세요. 이미 로그인된 PC는 바로 공방을 시작할 수 있습니다. 계정 설정에서 기기 코드 로그인이 허용되어 있어야 합니다. 기존 ChatGPT 계정으로 직접 로그인하며 API 키는 필요하지 않습니다.
4. 사진 선택 또는 촬영 → 화풍 선택 → 그림 만들기 → 위치·확대·회전 조절 → PNG/PDF 출력 순서로 진행하세요.

Windows 10/11 x64와 인터넷 연결이 필요합니다. Node.js와 Codex CLI는 묶음에 포함됩니다. Codex 앱 설치와 별개로 CLI 로그인 확인이 필요할 수 있습니다. 본인의 Codex 사용 한도와 내장 이미지 생성 도구를 이용합니다. 계정의 이미지 생성 기능이 없거나 한도가 소진되면 화면에서 실패 사유를 알려줍니다. API 과금 경로로 자동 전환하지 않습니다.

## GitHub 웹앱 · 모바일 링크·QR과 업데이트

웹앱 주소: https://ny-colab.github.io/ai-coaster-studio/

v1.4.0부터 기본 웹 주소는 운영자용입니다. 이 주소를 운영자들에게 공유하면 각자가 자기 PC를 연결하고 자기 Codex 계정으로 로그인합니다. 운영자가 발급한 행사 QR은 참가자 체험 화면으로 자동 연결합니다. 참가자 설치·로그인은 필요하지 않습니다. 웹의 사진·생성·출력 요청은 해당 PC에서 처리되므로 운영자 PC의 앱과 인터넷 연결을 유지해야 합니다.

앱 상단 **모바일 체험 · QR**에서 시간·생성 요청 수를 설정하고 시작하세요. 링크 복사와 QR 저장을 제공합니다. 휴대폰에서는 다운로드 없이 입장합니다. 종료 버튼 또는 시간 만료 시 기존 접속도 차단합니다. 자세한 내용은 [모바일 체험 안내](REMOTE.ko.md)를 확인하세요.

앱에서 새 버전을 확인하고 체험·앱 종료 후 UPDATE.cmd를 실행하면 GitHub 릴리스의 검증된 ZIP을 새 폴더에 준비합니다. 기존 작품만 복사하고 기존 폴더는 보존합니다.

## 사진과 디자인

JPG/PNG 사진(15MB 이하)을 사용하세요. 인물이 중앙에 있고 얼굴과 머리가 잘리지 않은 사진이 좋습니다. 카메라 권한을 거부해도 파일 업로드로 진행할 수 있습니다. 생성 시 사진은 Codex에 전송됩니다. 촬영과 사용에 동의한 사진을 준비하세요.

수채화·크레파스·캐리커처 화풍을 선택할 수 있습니다. 한 번에 한 장씩 생성하며 완료 전 중복 생성은 막습니다. 네트워크 오류 등으로 완료가 불확실할 때 자동 재제출하지 않습니다. 이전 작품은 아래 목록에서 다시 열 수 있습니다. 원형이 기본이며 사각형도 사용할 수 있습니다. 점선은 가장자리에서 5mm 안쪽의 참고선입니다.

## 9cm 출력

기본 지름은 **90mm**입니다. 화면 크기와 실제 출력 크기는 다릅니다. PNG는 300ppi, 90mm 기준 1063×1063px이며 원형 바깥은 투명합니다. PDF는 A4에 실제 mm 치수로 배치합니다. 90mm는 한 페이지 최대 6개, 120mm는 최대 2개이며 초과 수량은 다음 페이지에 배치합니다. '매수'는 그림 복제 수량입니다.

PDF 인쇄창에서 **실제 크기/100%**, **페이지에 맞추기 해제**를 선택하세요. 설정의 **A4 크기 확인용 PDF**를 먼저 인쇄해 90mm 원과 50mm 눈금을 자로 확인하세요. 실제 프린터의 배율과 도자기 치수는 행사 전 확인해야 합니다. 인쇄는 운영자가 PDF 미리보기를 확인하고 실행합니다.

## 종료·저장·삭제

**다음 참가자**로 다음 체험을 시작하세요. 앱 종료는 설정의 **앱 종료**를 사용합니다. 브라우저만 닫으면 서버는 계속 실행될 수 있습니다. 다시 START.vbs를 실행하면 해당 폴더의 서버를 재사용합니다. 생성 중 종료는 막습니다.

원본, 작품, 편집값, 내보낸 파일은 압축 해제 폴더의 `data/`에 보관됩니다. 행사 종료 후 **이 기기의 사진·작품 모두 지우기**로 앱에 저장된 자료를 삭제할 수 있습니다. 별도로 다운로드한 파일, Codex의 사용자 폴더 이미지 캐시와 서비스 기록은 지워지지 않으며 각각 관리해야 합니다. 계정 인증은 ZIP에 포함되지 않습니다.

## 문제 해결

- 연결 필요: 첫 화면에서 로그인하세요. **연결 다시 확인**으로 즉시 상태를 갱신할 수 있습니다. 기기 코드 로그인이 제한된 계정이면 Codex 공식 앱/CLI에서 직접 로그인한 뒤 재시작하세요.
- 이미지 도구 사용 불가: Codex 업데이트와 계정의 이미지 생성 사용 가능 여부를 확인하세요.
- 한도 초과: 표시된 계정 한도 회복 후 재시도하세요. 무료·무제한 사용은 보장하지 않습니다.
- 실행 실패: START.cmd의 메시지와 `data/startup.log`를 확인하세요. 한글·공백 경로를 지원합니다.
- 브라우저 재시작: 작업은 계속 진행됩니다. 운영자 직접 작업은 서버 재시작 후 기존 프로세스와 결과를 확인하며 자동 재제출하지 않습니다. 모바일 작업은 서버 재시작 시 종료합니다.

## 소스 개발

소스 ZIP은 Node.js 24.11.1에서 `npm ci`, `npm run build`, `npm start`로 실행합니다. `npm test`는 출력 치수·투명도·환경변수 검사입니다. `npm run package:portable`은 Windows x64에서 공식 런타임을 다운로드해 실행용/소스 ZIP을 만듭니다. 개발용 인증과 사용자 자료를 소스 저장소에 넣지 마세요.
