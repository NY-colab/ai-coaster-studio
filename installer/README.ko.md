# 작은 시작 프로그램

1. 이 ZIP을 압축 해제하고 START-LITE.cmd를 더블클릭하세요.
2. 처음 실행할 때 필요한 프로그램을 GitHub에서 내려받습니다. 설치된 Codex CLI 또는 Codex 데스크톱 앱의 실행 파일(0.160.1 이상)을 찾으면 재사용해 큰 Codex 묶음을 생략합니다. 찾지 못하면 전체 묶음을 받습니다.
3. 연결 화면에서 '이 PC를 웹 운영자 화면에 연결'을 눌러 웹앱을 사용하세요. 필요한 경우 본인의 Codex 계정으로 로그인합니다.
4. 다음에도 같은 START-LITE.cmd를 실행하세요. 설치가 유지되어 있으면 다시 다운로드하지 않습니다. 행사 중 PC와 연결 프로그램을 켜 두세요.

Windows 10/11 x64용입니다. 첫 설치에는 인터넷과 충분한 저장 공간이 필요합니다. 이 시작 파일만으로 이미지가 생성되는 것은 아니며, 첫 실행 시 실제 프로그램이 추가됩니다. 기존 Codex 앱이나 계정 정보를 수정하지 않습니다. API 키는 필요하지 않습니다.

사진·결과는 이 폴더 안 app/data에 저장됩니다. 기존 전체 묶음의 data 폴더는 자동으로 가져오지 않습니다. 같은 행사 도중 실행 방식을 바꾸지 말고, 기존 작품은 기존 앱에서 내보내세요. 앱의 데이터 삭제는 이 설치의 app/data에만 적용됩니다.

오류가 나면 창의 메시지를 확인하세요. 호환 Codex가 업데이트·삭제되어 감지되지 않으면 다음 실행 시 전체 묶음이 필요할 수 있습니다. 설치 중 실패한 폴더는 보존되며 새 폴더에 시작 파일을 풀어 다시 실행할 수 있습니다. 자동으로 생성 요청을 재전송하지 않습니다.

전체 묶음의 START.vbs는 그대로 사용할 수 있습니다. 최신 배포 안내: https://ny-colab.github.io/ai-coaster-studio/
