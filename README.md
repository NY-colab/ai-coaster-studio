# 동그란 순간 · AI 티코스터 공방

사진을 수채화·크레파스·캐리커처 티코스터로 만드는 Windows 운영자용 웹앱입니다.
운영자 PC의 **Codex CLI + ChatGPT 로그인**으로 자동 생성합니다. API 키는 필요하지 않습니다.

## 웹에서 바로 열기

**https://ny-colab.github.io/ai-coaster-studio/**

이 주소를 **운영자들에게 공유**하세요. 각 운영자는 자기 PC의 Codex 계정에 연결한 뒤 웹에서 로그인·사진 생성·QR 발급·행사 종료를 관리합니다. 각 PC의 계정과 행사는 독립적입니다.

## 운영자 PC 준비

1. 웹앱에서 **작은 시작 파일 받기 · 4KB**를 누르고 압축을 풉니다. Windows 10/11 x64용입니다. 첫 실행 때 호환 Codex(0.160.1 이상)가 설치되어 있으면 재사용하고 연결 프로그램 약 82MB를 받습니다. Codex가 없으면 전체 묶음 약 240MB를 받습니다. 두 번째부터는 다운로드 없이 실행합니다.
2. **START-LITE.cmd** 실행 → **이 PC에서 공방 열기**. 운영 화면은 이 PC의 브라우저에서 열립니다. 참가자는 발급된 QR로 GitHub 웹앱에 접속합니다.
3. 웹앱에서 **Codex로 로그인하기** → 공식 ChatGPT 로그인 → **공방 시작하기**. 이미 이 PC에서 로그인되어 있다면 연결 상태를 확인하고 시작합니다.
4. **모바일 체험 · QR**에서 시간·생성 한도를 설정하고 QR을 참가자에게 전달합니다.

연결 프로그램은 v1.4.1 이상이 필요합니다. 처음에 한 번 내려받고 행사 때마다 실행해 두세요. 브라우저만으로 PC의 Codex 실행 파일을 직접 실행할 수 없어 로컬 연결 프로그램이 필요합니다. 이미 실행 중이면 웹앱의 **이 PC에서 공방 열기**를 누르세요. 기본 포트 4318이 사용 중일 때는 시작 파일을 다시 실행하면 올바른 연결 화면이 열립니다. Chrome 또는 Edge를 사용하세요.

운영자 화면은 127.0.0.1에서만 열립니다. 행사 종료에는 반드시 **체험 즉시 종료**를 누르세요. 브라우저 탭만 닫아서는 행사가 종료되지 않습니다. 연결 프로그램을 종료하거나 PC를 끄면 참가자도 접속할 수 없습니다. 계정 인증과 작품은 각 PC에 보관하며 GitHub에는 저장하지 않습니다.

## 참가자는 다운로드 없이 QR로 접속

앱 위쪽 **모바일 체험 · QR** → 시간과 전체 생성 요청 한도 설정 → **모바일 체험 시작**을 누릅니다.
화면에 생긴 링크를 복사하거나 QR을 저장하여 전달하세요. 휴대폰에서는 QR/링크를 열기만 하면 됩니다.
운영자 PC를 계속 켜 두고 절전 모드를 해제하세요.

**체험 즉시 종료 · 모바일 연결 끊기**를 누르거나 설정 시간이 지나면 기존 링크·QR·세션이 무효화됩니다.
서버에서도 재검증하므로 휴대폰 화면을 계속 켜 놓아도 새 Codex 요청을 보낼 수 없습니다.
실행 중인 모바일 생성도 중단을 요청합니다. 이미 전송된 요청의 서비스 측 처리나 소모한 할당량을 되돌리지는 못합니다.
서버를 재시작하면 체험은 닫힌 상태로 시작합니다. 운영자 PC의 직접 사용은 계속 가능합니다.

참가자는 같은 브라우저 세션에서 만든 사진·작품만 조회할 수 있습니다. 운영자는 전체 결과를 확인합니다.
한 번에 한 장을 생성하며 다른 참가자가 생성 중이면 잠시 기다리라는 안내가 표시됩니다. 대기 요청을 자동 재제출하지 않습니다.

링크에는 입장 권한이 들어 있으므로 행사 참가자에게만 전달하세요. 외부 연결은 Cloudflare Quick Tunnel을 사용합니다.
주소는 매 행사 시작마다 바뀌며 PC·인터넷·터널이 켜져 있을 때만 동작합니다. GitHub Pages만으로 Codex를 실행하는 구조는 아닙니다.

## 업데이트

앱의 모바일 체험 관리 화면에서 **새 버전 확인**으로 GitHub 릴리스를 확인할 수 있습니다.
모바일 체험을 종료하고 설정에서 앱을 종료한 다음 **UPDATE.cmd**를 실행하세요.
최신 ZIP의 SHA-256을 확인하고, 새 버전 폴더를 현재 폴더 옆에 만듭니다.
사진·작품·내보낸 파일만 복사하고, 이전 폴더는 보존합니다. 새 폴더의 START.vbs로 실행하세요.
실행 중인 서버 상태와 모바일 입장 권한은 옮기지 않습니다. 새 버전이 없으면 다운로드하지 않습니다.

## 경량 배포

START.vbs 자체는 566바이트이며 기존 ZIP의 대부분은 런타임입니다. 경량판은 이미 설치된 Codex를 재사용해 중복 다운로드를 줄입니다. 시작 ZIP은 4KB이며 총 설치 용량을 뜻하지 않습니다. [경량 실행 안내](installer/README.ko.md). 기존 전체 묶음은 계속 사용할 수 있습니다. 경량판 데이터는 시작 폴더의 `app/data`에 보관하며 기존 전체 묶음의 데이터와 자동 합치지 않습니다.

`npm run package:lite`는 검증된 현재 버전의 전체 ZIP에서 Codex 묶음을 제외한 Bridge ZIP과 시작 ZIP, LITE-MANIFEST.json을 생성합니다. 게시된 전체 ZIP은 변경하지 않습니다. 시작 파일은 HTTPS로 받아 SHA-256 검증 후 설치합니다.
