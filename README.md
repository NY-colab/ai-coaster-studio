# 동그란 순간 · AI 티코스터 공방

사진을 수채화·크레파스·캐리커처 티코스터로 만드는 Windows 운영자용 웹앱입니다.
운영자 PC의 **Codex CLI + ChatGPT 로그인**으로 자동 생성합니다. API 키는 필요하지 않습니다.

## 바로 시작

1. [최신 Windows 실행용 ZIP](https://github.com/NY-colab/ai-coaster-studio/releases/latest/download/AI-Coaster-Studio-Windows-x64.zip)을 운영자 PC에서 내려받아 전체 압축을 풉니다.
2. **START.vbs**를 더블클릭하고 설정에서 Codex 로그인 상태를 확인합니다.
3. 사진 준비 → 화풍 선택 → 그림 만들기 → 90mm 편집 → PNG/A4 PDF 저장.

Windows 10/11 x64, 인터넷 연결이 필요합니다. Node.js, Codex CLI, Cloudflared가 포함됩니다. 계정 정보와 참가자 사진은 배포 파일에 포함하지 않습니다.

## 참가자는 다운로드 없이 QR로 접속

앱 위쪽 **모바일 체험 · QR** → 시간과 전체 생성 요청 한도 설정 → **모바일 체험 시작**을 누릅니다.
화면에 생긴 링크를 복사하거나 QR을 저장하여 전달하세요. 휴대폰에서는 QR/링크를 열기만 하면 됩니다.
운영자 PC를 계속 켜 두고 절전 모드를 해제하세요.

**체험 즉시 종료 · 모바일 연결 끊기**를 누르거나 설정 시간이 지나면 기존 링크·QR·세션이 무효화됩니다.
서버에서도 재검증하므로 휴대폰 화면을 계속 켜 놓아도 새 Codex 요청을 보낼 수 없습니다.
실행 중인 모바일 생성도 중단을 요청합니다. 이미 전송된 요청의 서비스 측 처리나 소모한 할당량을 되돌리지는 못합니다.
서버를 재시작하면 체험은 닫힌 상태로 시작합니다. 운영자 PC의 직접 사용은 계속 가능합니다.

참가자는 같은 브라우저 세션에서 만든 사진·작품만 조회할 수 있습니다. 운영자는 전체 결과를 확인합니다.
한 번에 한 장을 생성하며 다른 참가자가 생성 중이면 잠시 기다리라는 안내가 표시됩니다. 대기 요청을 자동 재제출하지 않습니다.

링크에는 입장 권한이 들어 있으므로 행사 참가자에게만 전달하세요. 외부 연결은 Cloudflare Quick Tunnel을 사용합니다.
주소는 매 행사 시작마다 바뀌며 PC·인터넷·터널이 켜져 있을 때만 동작합니다. GitHub Pages만으로 Codex를 실행하는 구조는 아닙니다.

## 업데이트

앱의 모바일 체험 관리 화면에서 **새 버전 확인**으로 GitHub 릴리스를 확인할 수 있습니다.
모바일 체험을 종료하고 설정에서 앱을 종료한 다음 **UPDATE.cmd**를 실행하세요.
최신 ZIP의 SHA-256을 확인하고, 새 버전 폴더를 현재 폴더 옆에 만듭니다.
사진·작품·내보낸 파일만 복사하고, 이전 폴더는 보존합니다. 새 폴더의 START.vbs로 실행하세요.
실행 중인 서버 상태와 모바일 입장 권한은 옮기지 않습니다. 새 버전이 없으면 다운로드하지 않습니다.

- Node.js **24.11.1**: `npm ci` → `npm run build` → `npm start`
- `npm test`: 출력 치수, 참가자 자료 격리, 종료 시 요청 차단, 세션·CSRF·할당량 제한 검사. 테스트는 실제 이미지를 생성하거나 Codex 한도를 사용하지 않습니다.
- Windows x64에서 `npm run package:portable`로 공식 런타임을 내려받아 검증 후 실행용/소스 ZIP을 만듭니다. 터널 바이너리는 고정 버전과 SHA-256으로 검사합니다.
- 새 릴리스는 package.json, server/common.mjs, launcher.mjs의 버전을 맞추고 lockfile을 갱신한 뒤 Windows CI와 패키지를 검증하여 게시합니다.

기본 출력: 90mm, PNG 300ppi(1063px), A4 PDF 최대 6개. 프린터에서 실제 크기 100%를 선택하고 크기 확인용 PDF로 실측하세요.
Codex 사용 한도와 해당 계정의 이미지 생성 도구를 사용하며 무료·무제한 사용을 보장하지 않습니다.
